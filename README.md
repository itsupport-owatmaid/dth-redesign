## จุดเด่นของรุ่นนี้

- **ธีม Human & Natural** — พื้นกระดาษครีม, เขียวธรรมชาติ (คงสี brand #90C73E), font มีหัว Mitr/Sarabun, เงานุ่ม, มุมโค้ง organic
- **เมนูใหม่ 5 หมวด** — หน้าแรก / เกี่ยวกับเรา / เครือข่าย / ข่าวสารและกิจกรรม / ข้อมูลสำคัญ (เมนูที่ยังไม่มีหน้า ทำเครื่องหมายขีดแดง + "หน้าเมนูนี้ยังไม่เรียบร้อย")
- **Accessibility ครบ** — ปรับขนาดอักษร 3 ระดับ, โหมดตัดกันสูง 2 แบบ (ขาว/เหลืองพื้นดำ), skip link, รองรับ `prefers-reduced-motion`
- **Icon เอกรูป** — SVG เส้นโทนเขียวทั้งเว็บ (แทน emoji หลากสี) เปลี่ยนสีตามโหมด contrast อัตโนมัติ
- **Responsive มือถือ** — การ์ด 2 คอลัมน์, โลโก้เครือข่าย 4 คอลัมน์, แท็บสิทธิ 2×2, hero จัดปุ่มไม่ทับ caption, font ไล่ขนาดไม่เบียดบรรทัด
- **Animation** — scroll-reveal + stagger ทั้งเว็บ, hero caption ไล่จังหวะ, แถบ "กลับไปด้านบนเว็บไซต์" เลื่อนขึ้นจากขอบล่าง (ดันปุ่มติดต่อลอยขึ้นพ้นกัน)
- **ข้อมูลทางการครบถ้วน** — เนื้อหา about คัดลอกตรงตามต้นฉบับ dth.or.th ทุกตัวอักษร (ข้อตกลงการคงข้อความตามกฎหมาย)

## หมายเหตุสำหรับงานต่อ

- เมนูรอเนื้อหา 4 รายการ: เจ้าหน้าที่สมาคม · สภาฯ ประจำจังหวัด · ข้อเสนอ · DTH-Magazine — พร้อมเนื้อหาเมื่อไหร่ ใส่ `href` คืนแล้วลบ class `pending`
- ข่าว/บทความฉบับเต็มลิงก์ไปเว็บทางการ dth.or.th
- ไฟล์ดีไซน์รุ่นก่อนหน้า: `dth-redesign.html` + `dth-styles.css` (เก็บไว้อ้างอิง)
