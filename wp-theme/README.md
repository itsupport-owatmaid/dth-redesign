# ธีม WordPress สำหรับเว็บไซต์ DTH

แปลงเว็บไซต์ HTML เดิม (`dth-v2.html` และหน้าอื่น ๆ) ให้เป็น **ธีม WordPress แบบ Classic เต็มรูปแบบ**
เจ้าหน้าที่สมาคมแก้ไขเนื้อหาได้ทุกส่วนผ่านหลังบ้าน โดยหน้าตาเว็บยังเหมือนเดิมทุกประการ

## ติดตั้ง (3 ขั้นตอน)

### 1. อัปโหลดธีม

1. ดาวน์โหลดไฟล์ `dth-theme.zip`
2. เข้าหลังบ้าน WordPress → **รูปแบบเว็บ (Appearance) → ธีม (Themes) → เพิ่มธีมใหม่ → อัปโหลดธีม**
3. เลือกไฟล์ `dth-theme.zip` → **ติดตั้ง** → **เปิดใช้งาน**

> ถ้าอัปโหลดไม่ได้เพราะไฟล์ใหญ่เกินขีดจำกัด ให้แตกไฟล์ zip แล้วอัปโฟลเดอร์ `dth-theme`
> เข้าไปที่ `wp-content/themes/` ผ่าน FTP หรือ File Manager ของ cPanel แทน

### 2. นำเข้าเนื้อหาเดิม

1. เข้า **เครื่องมือ (Tools) → นำเข้าเนื้อหา DTH**
2. กด **“นำเข้าเนื้อหาทั้งหมด”** — ระบบจะสร้างให้อัตโนมัติ:
   - ข่าวสารและกิจกรรม 7 รายการ พร้อมหมวดหมู่
   - คลังสื่อและเอกสาร 8 รายการ
   - คณะกรรมการและเจ้าหน้าที่ 42 คน (แยกกลุ่ม กรรมการบริหาร / กรรมการ / เจ้าหน้าที่)
   - สภาฯ ประจำจังหวัด 67 จังหวัด แยกตาม 4 ภูมิภาค
   - องค์การสมาชิก 6 องค์การ + หน่วยงานที่เกี่ยวข้อง 8 หน่วยงาน
   - สไลด์หน้าแรก, แท็บสิทธิคนพิการ 4 หมวด, คำถามที่พบบ่อย 4 ข้อ, ข้อเสนอเชิงนโยบาย
   - หน้า “เกี่ยวกับเรา” และ “ข้อบังคับ/ระเบียบ” (เนื้อหาทางการครบทุกตัวอักษร)
   - เมนูหลักและเมนูท้ายเว็บ พร้อมตั้งหน้าแรกให้เรียบร้อย
3. กด **“เริ่มดึงรูปภาพ”** แล้วเปิดหน้าค้างไว้จนขึ้นว่าดึงครบ
   (รูปจะถูกดาวน์โหลดเข้าคลังสื่อ เพื่อให้เปลี่ยนรูปเองได้ในภายหลัง)

> กดปุ่มนำเข้าซ้ำได้ปลอดภัย — รายการที่นำเข้าไปแล้วจะถูกข้าม ไม่สร้างซ้ำ
> และไม่ทับเนื้อหาที่แก้ไขเอง

### 3. ตั้งค่าปิดท้าย

1. **ตั้งค่า → ลิงก์ถาวร** → กด **บันทึก** 1 ครั้ง (จำเป็น เพื่อให้ลิงก์ข่าว/จังหวัด/สื่อทำงาน)
2. **รูปแบบเว็บ → ปรับแต่ง → ตั้งค่าเว็บไซต์ DTH** → แก้ที่อยู่ เบอร์โทร อีเมล โซเชียลมีเดีย

เสร็จแล้ว — เว็บพร้อมใช้งานจริง

## แก้ไขเนื้อหาตรงไหน

| อยากแก้ | ไปที่เมนูหลังบ้าน |

| ประธานสภาฯ จังหวัด (ชื่อ เบอร์โทร) | **สภาฯ ประจำจังหวัด** |
| ข้อเสนอเชิงนโยบาย + ไฟล์ PDF | **ข้อเสนอเชิงนโยบาย** |
| สไลด์ภาพใหญ่หน้าแรก | **สไลด์หน้าแรก** |
| แท็บ “สิทธิคนพิการที่ควรรู้” | **สิทธิคนพิการ** |
| คำถามที่พบบ่อยหน้าแรก | **คำถามที่พบบ่อย** |
| โลโก้องค์การสมาชิก / หน่วยงาน | **องค์การสมาชิกและเครือข่าย** |
| หน้าเกี่ยวกับเรา ข้อบังคับ ฯลฯ | **หน้า (Pages)** |

| โลโก้สมาคม | **รูปแบบเว็บ → ปรับแต่ง → อัตลักษณ์เว็บไซต์** |

### การจัดลำดับ

โพสต์ทุกชนิดเรียงตามช่อง **“ลำดับ” (Order)** ในกล่อง *คุณสมบัติของหน้า* ด้านขวา
ตัวเลขน้อยมาก่อน ถ้าเท่ากันจะเรียงตามวันที่ใหม่สุดก่อน

## สิ่งที่ธีมนี้คงไว้จากเว็บเดิม

- **แถบช่วยการเข้าถึง** — ปรับขนาดตัวอักษร 3 ระดับ และโหมดคอนทราสต์สูง 2 แบบ
  (ขาวพื้นดำ / เหลืองพื้นดำ) พร้อม **จำค่าที่ผู้ใช้เลือกไว้** ข้ามหน้าและข้ามการเข้าชมครั้งถัดไป
- skip link, `aria-*`, `role`, focus-visible, รองรับ `prefers-reduced-motion`
- ดีไซน์ “Human & Natural” สีเขียว `#90C73E` เดิมทั้งหมด (ใช้ `dth-v2.css` ไฟล์เดียวกับเว็บเดิม)
- แอนิเมชัน scroll-reveal, hero slider, ปุ่มติดต่อลอย, ปุ่มกลับขึ้นด้านบน
- ฟอร์ม “ส่งข้อความถึงทีมงาน” — ของเดิมเป็นแค่หน้าจอจำลอง
  **ฉบับนี้ส่งอีเมลจริง** ไปยังที่อยู่ที่ตั้งไว้ในหน้าปรับแต่ง

## โครงสร้างไฟล์

```
dth-theme/
├── style.css                  ข้อมูลธีม + CSS ส่วนเสริมของ WordPress
├── functions.php              โหลดไฟล์ใน inc/
├── header.php  footer.php     แถบบน แถบช่วยเข้าถึง เมนู ท้ายเว็บ ปุ่มลอย
├── front-page.php             หน้าแรก
├── singular.php               หน้าเดี่ยวและเพจ
├── index.php  search.php  404.php  searchform.php
├── archive-dth_news.php       หน้ารวมข่าว (มีแท็บกรอง + ค้นหาในหน้า)
├── archive-dth_media.php      หน้าคลังสื่อ
├── archive-dth_person.php     คณะกรรมการ + เจ้าหน้าที่
├── archive-dth_province.php   สภาฯ จังหวัด แยกภูมิภาค
├── archive-dth_proposal.php   ข้อเสนอเชิงนโยบาย
├── template-parts/            ส่วนย่อยของหน้าแรกและการ์ด
├── inc/
│   ├── setup.php              theme support, เมนู, ขนาดรูป
│   ├── enqueue.php            โหลด CSS/JS
│   ├── post-types.php         ประเภทเนื้อหาและหมวดหมู่ทั้งหมด
│   ├── meta-boxes.php         ช่องกรอกข้อมูลเพิ่มในหน้าแก้ไข
│   ├── customizer.php         ตั้งค่าเว็บไซต์ DTH
│   ├── nav-walker.php         แปลงเมนู WordPress เป็นมาร์กอัปเดิม
│   ├── template-tags.php      ฟังก์ชันช่วย + ฟอร์มติดต่อ
│   ├── seed-data.php          เนื้อหาเดิมที่ถอดจาก HTML (สร้างอัตโนมัติ)
│   └── importer.php           หน้า Tools → นำเข้าเนื้อหา DTH
└── assets/                    CSS, JS, โลโก้
```

ไม่ต้องติดตั้งปลั๊กอินเพิ่มใด ๆ — ใช้ฟังก์ชันมาตรฐานของ WordPress ทั้งหมด

## สร้าง seed-data.php ใหม่

ถ้าแก้ไฟล์ HTML ต้นฉบับแล้วอยากอัปเดตเนื้อหาที่ importer ใช้:

```bash
pip install beautifulsoup4 lxml
python3 wp-theme/tools/generate-seed.py
```
