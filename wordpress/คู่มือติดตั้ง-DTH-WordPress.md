# คู่มือติดตั้งเว็บไซต์ DTH บน WordPress

> เว็บไซต์ **สมาคมสภาคนพิการทุกประเภทแห่งประเทศไทย (Disabilities Thailand)**
> สรุปสิ่งที่ทำ + วิธีติดตั้ง + วิธีแก้ปัญหาที่เจอ (อัปเดต 2026-06-16)

---

## 1. ภาพรวม — มี 2 เวอร์ชัน

| เวอร์ชัน | คืออะไร | แก้เนื้อหาผ่านหลังบ้าน | ไฟล์ |
|---|---|---|---|
| **Static (HTML)** | เว็บ HTML ล้วน 11 หน้า | ❌ แก้ไม่ได้ (ต้องแก้ไฟล์) | โฟลเดอร์ `dth-new` / ไฟล์ `.html` |
| **WordPress (ธีม)** | ธีม `dth-theme` แปลงจาก static | ✅ แก้ได้ในหลังบ้าน | `dth-theme.zip` |

**แนะนำใช้เวอร์ชัน WordPress** เพราะแก้เนื้อหาผ่าน admin ได้ + มีระบบจัดการจังหวัด

---

## 2. วิธีติดตั้ง WordPress (หัวใจ = 3 สเต็ป)

### สเต็ป 1 — เอาธีมขึ้นไป
แตกไฟล์ **`dth-theme.zip`** ลงใน:
```
wp-content/themes/
```
→ ได้โฟลเดอร์ `dth-theme` (ข้างในมี `style.css`, `functions.php`, `page-*.php`, `Pic/`, `Doc/`, `inc/`)

- ผ่านหน้าแอดมิน: รูปลักษณ์ > ธีม > เพิ่มธีมใหม่ > อัปโหลดธีม
- **ถ้าไฟล์ใหญ่เกินลิมิต (~48MB)** → ใช้ **File Manager / File Station** อัป zip เข้า `wp-content/themes/` แล้วคลิกขวา > แตกไฟล์

### สเต็ป 2 — เปิดใช้งานธีม ⭐ (สำคัญสุด)
`wp-admin` → **รูปลักษณ์ (Appearance) → ธีม (Themes)** → กด **เปิดใช้งาน (Activate)** ธีม **"DTH — Disabilities Thailand"**

> พอกด Activate โค้ดในธีมจะทำให้อัตโนมัติ:
> - สร้าง **11 หน้า** (หน้าแรก, เกี่ยวกับสมาคม, เจ้าหน้าที่, สภาฯ จังหวัด, ข่าวสาร, คลังสื่อ, DTH Magazine, ข้อเสนอเชิงนโยบาย, ข้อบังคับ/ระเบียบ, ผังเว็บไซต์, ขั้นตอนการพัฒนา)
> - ใส่ข้อมูล **68 จังหวัด**
> - ตั้ง **permalink** + **หน้าแรก** ให้

### สเต็ป 3 — เช็กความเรียบร้อย
- **หน้า (Pages)** → เผยแพร่ครบไหม (ถ้าเป็น "ฉบับร่าง" → เลือกทั้งหมด > Bulk edit > Published)
- **ตั้งค่า (Settings) → การอ่าน (Reading)** → หน้าแรกแสดง = "หน้าคงที่" → เลือก **"หน้าแรก"**
- **ตั้งค่า → ทั่วไป** → ตั้ง Site Title = `สภาคนพิการทุกประเภทแห่งประเทศไทย`, Tagline = `Disabilities Thailand`

## 3. ⚠️ ปัญหาที่เจอ + วิธีแก้ (สำคัญมาก)

### 3.1 ชื่อโฟลเดอร์ธีมต้องเป็น `dth-theme`
- ธีมที่ใช้งานจริงชื่อโฟลเดอร์ **`dth-theme`** — เวลาวาง/แก้ไฟล์ ต้องวางในโฟลเดอร์นี้เท่านั้น (ไม่ใช่ `dth`)
- โค้ดใช้ path แบบ dynamic (`DTH_URI`) จึงปรับตามชื่อโฟลเดอร์ให้เอง

### 3.2 รูปไม่ขึ้น — สาเหตุที่เจอ
| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| โลโก้หน่วยงานไม่ขึ้น | โค้ดชี้ URL ภายนอก `dth.or.th` / โฟลเดอร์ `file logo` มีเว้นวรรค | ไฟล์ล่าสุดแก้ให้ชี้ `Pic/logos/` (ไม่มีเว้นวรรค) + `Pic/external/` แล้ว |
| รูปชี้ไป dth.or.th | **Site URL ตั้งเป็น dth.or.th** แต่เปิดผ่าน IP | ตั้งค่า > ทั่วไป → แก้ WordPress/Site Address ให้ตรงกับ URL ที่เปิดจริง |

> ✅ **ไฟล์ธีมเวอร์ชันล่าสุด แก้เรื่องรูปให้ครบแล้ว** (self-contained ไม่พึ่งเว็บนอก)

### 3.3 หน้าหายเข้าถังขยะ
- ถ้าหน้าหาย → เช็ก **หน้า > Trash** → เลือกทั้งหมด > **Restore**
- หน้าที่กู้มาจะเป็น "ฉบับร่าง" → ต้อง **Publish** อีกที

## 4. การจัดการเนื้อหา (หลังบ้าน)

- **จังหวัด** → เมนู **"สภาฯ จังหวัด"** → เพิ่ม/แก้/ลบ ผ่านฟอร์ม (ภูมิภาค/ชื่อประธาน/ประเภท/เบอร์)
- **หน้าเนื้อหา** (เช่น ข้อเสนอเชิงนโยบาย) → เมนู **หน้า** → แก้เป็น "บล็อก HTML" ได้
  - ในเนื้อหาจะเห็นตัวแปร `{{DTH}}` (path รูป) และ `{{HOME}}` (ลิงก์) — **ห้ามลบ** ระบบแปลงเป็น URL จริงให้เอง
- *(กำลังทยอยทำ: ข่าว / กรรมการ / เจ้าหน้าที่ / สื่อ ให้แก้ผ่านหลังบ้านเหมือนจังหวัด)*

## 5. 🛟 การสำรองข้อมูล (ทำก่อนแก้อะไรใหญ่ ๆ เสมอ)

- ใช้ปลั๊กอิน **All-in-One WP Migration → Export** → ได้ไฟล์ `.wpress` เก็บไว้
- หรือ **Archive** โฟลเดอร์ `wp-content` + export ฐานข้อมูล

## 6. wp-config.php (สำหรับส่งมอบ/ย้าย hosting)

- ⚠️ **`wp-config.php` ตัวจริงไม่ได้รวมมากับธีม** (มีรหัสผ่าน DB + คีย์ลับ ห้ามขึ้น Git)
- ต้อง **สร้างใหม่เองบน hosting** โดยดูจาก template ที่ `wordpress-files/wp-config.php`
- สร้างคีย์ลับ (SALT) ใหม่จาก https://api.wordpress.org/secret-key/1.1/salt/
