## 2. ระบบจัดการผ่านฟอร์ม (CPT) — 5 ชุด

| เมนูในหลังบ้าน | ข้อมูล | ฟิลด์ในฟอร์ม | หน้าเว็บ / shortcode |
|---|---|---|---|
| 📍 **สภาฯ จังหวัด** | 68 จังหวัด | ภูมิภาค · ชื่อประธาน · ประเภทความพิการ · เบอร์โทร | `/provinces/` (ดึงอัตโนมัติในเทมเพลต) |
| 👥 **เจ้าหน้าที่** | 12 คน | ชื่อ · ตำแหน่ง · ลำดับ | `/staff/` → `[dth_staff]` |
| 🧑‍💼 **กรรมการ** | 30 คน (6 คนมีรูป) | ชื่อ · ตำแหน่ง · รูป · ลำดับ | `/about/` → `[dth_board_cards]` + `[dth_board_table]` |
| 📣 **ข่าวสาร** | 7 ข่าว | หัวข้อ · หมวด · ป้าย · รูปหน้าปก · อีโมจิสำรอง · วันที่ · ลิงก์ · คำโปรย | `/news/` → `[dth_news]` |
| 🖼️ **คลังสื่อ** | 8 ชิ้น | ชื่อ · หมวด · ป้าย · รูป · ลิงก์ · คำโปรย | `/media/` → `[dth_media]` |

### วิธีใช้งานประจำวัน
- **เพิ่มรายการ:** เมนูนั้น → **เพิ่ม...** → กรอกฟอร์ม → **เผยแพร่**
- **ลำดับการแสดง:** กล่อง **"คุณลักษณะหน้า → ลำดับ"** (เลขน้อยขึ้นก่อน)
- **ชื่อ/หัวข้อ** = ช่อง "ชื่อเรื่อง" ด้านบนของฟอร์ม
- หน้าเว็บอัปเดตตามอัตโนมัติ ไม่ต้องแก้ HTML

### หมวดที่ใช้ได้ (ช่อง "หมวด")
- **ข่าว:** `pr` · `activity` · `report` · `knowledge` · `knowledge health` · `knowledge general` · `knowledge blind`
- **สื่อ:** `rights` · `law` · `home` · `magazine`

### รูปภาพในฟอร์ม
- ใส่ **ชื่อไฟล์ในธีม** (เช่น `board-xxx.png`, `Pic/infographic/xxx.jpg`) หรือ **URL เต็ม** (`https://...`) ก็ได้
- รูปใหม่: อัปโหลดเข้า **สื่อ (Media)** → copy URL มาวางในช่องรูป

## 3. หน้าเนื้อหา (แก้ผ่าน editor)

7 หน้า: เกี่ยวกับสมาคม · เจ้าหน้าที่ · ข่าวสาร · คลังสื่อ · DTH Magazine · ข้อเสนอเชิงนโยบาย · ข้อบังคับ/ระเบียบ

### ⚠️ กฎสำคัญที่สุด: เนื้อหาต้องอยู่ใน "บล็อก HTML (Custom HTML)"
ถ้าวางผิดชนิดบล็อก → หน้าเว็บจะ **โชว์เป็นโค้ด** แทนที่จะแสดงผล

### วิธีวาง/แก้เนื้อหาที่ถูกต้อง (Code editor)
1. เปิดหน้านั้น → กด **⋮ (มุมขวาบน) → ตัวแก้ไขโค้ด (Code editor)**
2. ลบของเดิมทั้งหมด → วางโค้ด (ต้องมี `<!-- wp:html -->` บรรทัดแรก และ `<!-- /wp:html -->` บรรทัดสุดท้าย)
3. **⋮ → ตัวแก้ไขภาพ (Visual editor)** → **อัปเดต**

### ไฟล์โค้ดพร้อมวาง (backup)
อยู่ใน repo: `wordpress/page-content-paste/` — 1 ไฟล์ต่อ 1 หน้า (ใส่ shortcode + wp:html ไว้แล้ว)

### ตัวแปรในเนื้อหา — ห้ามลบ
- `{{DTH}}` = path ของธีม (รูป/เอกสาร)
- `{{HOME}}` = ที่อยู่เว็บ (ลิงก์ภายใน)
- ระบบแปลงเป็น URL จริงให้เองตอนแสดงผล → ย้ายโดเมน/โฟลเดอร์ได้ไม่พัง

## 4. หน้าแรก (front-page.php)

หน้าแรก**ยังแก้ผ่านไฟล์ธีม** (ไม่ใช่ editor) เพราะมีสไลด์/แท็บ/สคริปต์ซับซ้อน

**วิธีแก้:**
- **รูปลักษณ์ → แก้ไขไฟล์ธีม → หน้าแรก (front-page.php)** → วางทั้งไฟล์ทับ → อัปเดตไฟล์
- หรือวางทับผ่าน File Manager

**สิ่งที่เปลี่ยนแล้ว:**
- เอา 2 การ์ด "รู้จักการทำงานของสมาคม" + "องค์การสมาชิกและเครือข่าย" ออก → คำถามที่พบบ่อยเต็มแถว
- โลโก้หน่วยงาน → ใช้ `Pic/logos/` (local)
- ส่วน "ติดตาม DTH" → เปลี่ยนจาก iframe Facebook (พัง) เป็นปลั๊กอิน Smash Balloon

> ⚠️ แก้ใน Theme File Editor ให้ copy ทั้งไฟล์ทับ อย่าแก้ทีละบรรทัด — พิมพ์ผิดเว็บพังทั้งเว็บได้

## 5. Facebook feed (Smash Balloon)

**ทำไม:** Facebook Page Plugin (iframe) เดิมโชว์แค่หัวเพจ ไม่มีโพสต์ — Facebook ปิดการดึงโพสต์แบบไม่ล็อกอินแล้ว

**ติดตั้งแล้ว:** ปลั๊กอิน *Smash Balloon Facebook Feed* (active)

**ขั้นที่เหลือ — เชื่อมเพจ:**
1. ล็อกอิน Facebook (บัญชีที่**เป็นแอดมินเพจ DTH**) ใน Chrome ตัวเดียวกับ wp-admin
2. **Facebook Feed → All Feeds → Add New** → เลือก **Timeline**
3. **Add Source → Page** → Continue as… → เลือกเพจ **"สภาคนพิการทุกประเภทแห่งประเทศไทย"** → อนุญาตทั้งหมด
4. เลือก template → preview มีโพสต์ → **Save**
5. ดู shortcode ที่ได้:
   - `front-page.php` ตั้งไว้เป็น **`[custom-facebook-feed]`**
   - ถ้าได้เป็น `[custom-facebook-feed feed=1]` (มีเลข) → แก้บรรทัดใน `front-page.php` ให้ตรง

> ถ้ายังไม่ได้เชื่อม/ปิดปลั๊กอิน → หน้าแรกจะโชว์ปุ่ม "เปิดเพจ Facebook ของสมาคม" แทน (ไม่พัง)

## 7. ปัญหาที่เคยเจอ + วิธีแก้

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| หน้าเว็บโชว์เป็นโค้ด HTML | เนื้อหาไม่ได้อยู่ในบล็อก Custom HTML | วางใหม่ผ่าน Code editor พร้อม `<!-- wp:html -->` ครอบ |
| shortcode ขึ้นเป็นตัวอักษร `[dth_...]` | ยังไม่ได้วางไฟล์ CPT / functions.php ล่าสุด | วางไฟล์ `inc/cpt-*.php` + `functions.php` ลงธีม |
| รูปไม่ขึ้น | ไฟล์อยู่ผิดโฟลเดอร์ / ชื่อโฟลเดอร์มีเว้นวรรค / Site URL ผิด | วางใน `dth-theme/` · ใช้ `Pic/logos` · เช็ก ตั้งค่า > ทั่วไป |
| แก้ไฟล์แล้วหน้าเว็บไม่เปลี่ยน | วางผิดโฟลเดอร์ หรือ cache | วางใน `dth-theme/` · เปิด Incognito / Ctrl+F5 |
| หน้าหายทั้งหมด | ถูกย้ายไปถังขยะ | หน้า → Trash → เลือกทั้งหมด → Restore → แล้ว Publish |
| อัปโหลด zip แล้ว "ลิงก์หมดอายุ" | ไฟล์ใหญ่เกินลิมิต PHP | ใช้ File Manager อัป + แตก zip แทน |
| Facebook feed ว่าง | iframe เดิม / ยังไม่เชื่อมเพจ | ใช้ Smash Balloon + เชื่อมเพจ (ข้อ 5) |

## 8. ไฟล์ในธีม (สำคัญ)

```
dth-theme/
├─ functions.php            ← โหลดทุกระบบ (ทับทุกครั้งที่อัปเดต)
├─ front-page.php           ← หน้าแรก
├─ page-*.php               ← เทมเพลตแต่ละหน้า (เรียก the_content)
├─ dth-v2.css               ← สไตล์หลัก
├─ inc/
│  ├─ cms.php               ← CPT จังหวัด
│  ├─ cpt-staff.php         ← CPT เจ้าหน้าที่
│  ├─ cpt-board.php         ← CPT กรรมการ
│  ├─ cpt-news.php          ← CPT ข่าว
│  ├─ cpt-media.php         ← CPT สื่อ
│  ├─ page-content.php      ← เนื้อหาเริ่มต้น + ตัวแปลง {{DTH}}/{{HOME}}
│  └─ floating-contact.php  ← ปุ่มลอยติดต่อ
├─ Pic/  (logos/, external/, members/, provinces/, infographic/, รูปนายก/ ...)
└─ Doc/  (magazine/, proposals/ ...)
```

> ไฟล์ในธีมที่ไม่ได้ใช้: `archive-dth_*.php`, `template-parts/`, `search.php`, `singular.php`, `404.php` (มีคนเพิ่มไว้ ไม่ได้ถูกเรียก — ลบได้ ไม่กระทบ)
