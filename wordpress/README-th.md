# เว็บไซต์ DTH เวอร์ชัน WordPress (รันบนเครื่องด้วย Docker)

แปลงเว็บไซต์ static เดิม (11 หน้า) เป็น **WordPress theme ชื่อ `dth`** โดย**คงหน้าตาและฟีเจอร์การเข้าถึง (a11y bar / คอนทราสต์สูง / ปรับขนาดอักษร) ไว้ครบ 100%** พร้อมชุด Docker สำหรับรันบนเครื่องตัวเองแบบคำสั่งเดียว

---

## สิ่งที่ต้องมีก่อน
- **Docker Desktop** (Windows/macOS) — ติดตั้งจาก https://www.docker.com/products/docker-desktop/ แล้วเปิดให้ทำงาน

## วิธีรัน (คำสั่งเดียว)

1. ดึงโค้ดสาขานี้ลงเครื่อง (หรือดาวน์โหลด ZIP จาก GitHub สาขา `claude/vigilant-fermat-fdf363`)
   ```bash
   git clone <repo-url>
   cd dth-redesign
   git checkout claude/vigilant-fermat-fdf363
   ```
2. เข้าโฟลเดอร์ `wordpress/` แล้วสั่งรัน:
   ```bash
   cd wordpress
   docker compose up -d
   ```
   ครั้งแรกจะดาวน์โหลด image + ติดตั้ง WordPress + สร้างหน้าทั้ง 11 หน้า + เปิดใช้ธีมให้อัตโนมัติ (รอ ~1–2 นาที)

3. เปิดเบราว์เซอร์:
   - **เว็บไซต์:** http://localhost:8080
   - **หน้าแอดมิน:** http://localhost:8080/wp-admin
     - ผู้ใช้: `admin`  ·  รหัสผ่าน: `admin123`

> ดูสถานะการติดตั้งอัตโนมัติได้ด้วย `docker compose logs -f wpcli`

## คำสั่งที่ใช้บ่อย
```bash
docker compose up -d        # เปิดเว็บ
docker compose down         # ปิดเว็บ (ข้อมูลยังอยู่)
docker compose down -v      # ปิด + ลบฐานข้อมูลทั้งหมด (เริ่มใหม่หมด)
docker compose logs -f wpcli   # ดู log การติดตั้งอัตโนมัติ
```

## โครงสร้างไฟล์
```
wordpress/
├─ docker-compose.yml          # WordPress + MariaDB + ตัวติดตั้งอัตโนมัติ
├─ init/setup.sh               # สคริปต์ติดตั้ง/สร้างหน้า/เปิดธีม
└─ wp-content/themes/dth/      # ★ ธีม DTH
   ├─ style.css                # หัวธีม (ชื่อ/รายละเอียด)
   ├─ functions.php            # โหลดฟอนต์ + dth-v2.css
   ├─ header.php / footer.php  # <head> และปิด body
   ├─ dth-v2.css               # สไตล์หลัก (สำเนาจากเว็บเดิม)
   ├─ front-page.php           # หน้าแรก
   └─ page-*.php               # อีก 10 หน้า (about, staff, provinces, news, ...)
```
รูปภาพ (`Pic/`) และเอกสาร (`Doc/`) ใช้วิธี **bind-mount จาก repo** เข้าไปในธีมตอนรัน จึงไม่ต้องสำเนาซ้ำ และแก้รูปใน repo แล้วเห็นผลทันที

## การแก้เนื้อหา
- **เนื้อหาในหน้า (รวมหน้าแรก):** หน้าแอดมิน → **หน้า (Pages)** → แก้ในบล็อก **HTML แบบกำหนดเอง**
  ตัวแปร `{{DTH}}` (path รูปในธีม) และ `{{HOME}}` (ที่อยู่เว็บ) ระบบแปลงเป็น URL จริงให้เอง — **ห้ามลบ**
  เนื้อหาตั้งต้นของทุกหน้าอยู่ที่ `inc/page-content.php` และมีสำเนาไว้ก็อปวางที่ `page-content-paste/`
- **ข้อมูลรายการ:** ภาพแบนเนอร์ / จังหวัด / เจ้าหน้าที่ / กรรมการ / ข่าวสาร / คลังสื่อ — แก้ผ่านฟอร์มในเมนูซ้ายของแอดมิน (custom post type)
- **โครงเว็บ (เมนู · แถบ a11y · ฟุตเตอร์ · สคริปต์):** อยู่ในไฟล์ `front-page.php` / `page-*.php` ของธีม
- **ปุ่มลอยติดต่อ + ฟอร์ม "ส่งข้อความถึงทีมงาน":** อยู่ใน `inc/floating-contact.php` (แสดงทุกหน้าอัตโนมัติ)
- **ชื่อหน้า/permalink:** จัดการได้ในหน้าแอดมิน → Pages

## ภาพแบนเนอร์หน้าแรก

เมนู **ภาพแบนเนอร์** — เพิ่ม/เปลี่ยนรูป/แก้ข้อความ/สลับลำดับสไลด์ได้เอง ไม่ต้องแตะโค้ด

| ช่อง | ใช้ทำอะไร |
|---|---|
| ชื่อเรื่อง | หัวข้อใหญ่บนแบนเนอร์ |
| รูปแบนเนอร์ (กล่องขวา) | เลือกจากคลังสื่อหรืออัปโหลดใหม่ — แนะนำกว้าง 1920px |
| ป้ายเล็กเหนือหัวข้อ | เช่น "ยินดีต้อนรับ" (เว้นว่าง = ไม่แสดง) |
| คำอธิบายใต้หัวข้อ | ข้อความรองใต้หัวข้อ |
| ลิงก์ปุ่ม + ข้อความบนปุ่ม | ใส่ถ้าต้องการปุ่มบนแบนเนอร์ (เว้นว่าง = ไม่มีปุ่ม) |
| คุณลักษณะหน้า (ลำดับ) | ลำดับสไลด์ เลขน้อยมาก่อน |

- ซ่อนแบนเนอร์ชั่วคราว: เปลี่ยนสถานะเป็น **ฉบับร่าง** ข้อมูลยังอยู่แต่ไม่แสดงบนเว็บ
- มีสไลด์เดียว = ไม่แสดงลูกศรกับจุด (ปุ่มที่กดแล้วไม่เกิดอะไรทำให้ screen reader สับสน)
  ตั้งแต่ 2 สไลด์ขึ้นไปจะเลื่อนอัตโนมัติและมีปุ่มควบคุมให้
- หน้าแรกเรียกแบนเนอร์ผ่าน shortcode `[dth_hero]`

**เว็บที่ติดตั้งไปก่อนมีเมนูนี้:** เนื้อหาหน้าแรกจะมี markup แบนเนอร์ฝังอยู่ในตัวหน้า
เข้าเมนู **ภาพแบนเนอร์** จะมีแถบแจ้งเตือนพร้อมปุ่มให้กดเปลี่ยนมาใช้เมนูนี้ครั้งเดียว
(หน้าตาเว็บไม่เปลี่ยน · เนื้อหาเดิมถูกสำรองไว้ใน meta `dth_hero_backup` ของหน้านั้น)

## ข้อความจากฟอร์ม "ส่งข้อความถึงทีมงาน"

ฟอร์มส่งของจริงแล้ว (ไม่ใช่เดโม) — ทุกข้อความถูก **เก็บในหลังบ้านเสมอ** ที่เมนู **ข้อความติดต่อ**
แม้อีเมลหรือ LINE จะส่งไม่ออกก็ไม่หาย และแต่ละรายการบอกสถานะการแจ้งเตือนไว้ให้ดู

ตั้งค่าช่องทางแจ้งเตือนที่ **ข้อความติดต่อ > ตั้งค่าการแจ้งเตือน**

| ช่องทาง | สิ่งที่ต้องกรอก |
|---|---|
| อีเมล | อีเมลผู้รับ (ใส่หลายอีเมลได้ คั่นด้วย `,`) — ค่าเริ่มต้น `disabilitiesth@gmail.com` |
| LINE Official Account | Channel access token (long-lived) + User/Group ID ปลายทาง จาก LINE Developers Console |

> เว้นว่าง/ไม่ติ๊กเปิดใช้ = ช่องทางนั้นไม่ถูกส่ง (ข้อความยังเก็บในหลังบ้านตามปกติ)
>
> อีเมลส่งผ่าน `wp_mail()` ของ WordPress ถ้า hosting ไม่มีเมลเซิร์ฟเวอร์ ให้ลงปลั๊กอิน SMTP
> (เช่น WP Mail SMTP) แล้วสถานะจะเปลี่ยนจาก "ส่งไม่ออก" เป็น "ส่งแล้ว"

**กันสแปม/ความปลอดภัย:** nonce + honeypot + จำกัด 5 ข้อความต่อ IP ต่อ 10 นาที

**รองรับเว็บที่เปิดระบบแคชหน้าแล้ว** (SpeedyCache / LiteSpeed / WP Rocket ฯลฯ) — ฝั่งหน้าเว็บ
ขอ nonce สดผ่าน `admin-ajax.php` ก่อนส่งทุกครั้ง จึงไม่ต้องยกเว้นหน้าไหนจากแคช
(ถ้าผู้ใช้ปิด JavaScript แล้วเจอ "หมดเวลาการกรอกฟอร์ม" ให้รีเฟรชหน้าแล้วส่งใหม่)

## 🌐 ติดตั้งบน WordPress hosting จริง (เช่น http://10.10.110.10/wordpress/)

ธีมรองรับ subdirectory และ URL ใด ๆ อยู่แล้ว (ใช้ `home_url()` ทุกลิงก์) และจะ **สร้างหน้าทั้ง 11 หน้า + ตั้งหน้าแรก + เปิด permalink ให้อัตโนมัติเมื่อกดเปิดใช้ธีม**

**ขั้นตอน**
1. สร้างไฟล์ zip ของธีม (รวมรูป/เอกสาร):
   ```bash
   cd wordpress
   ./build-theme-zip.sh        # ได้ไฟล์ wordpress/dth-theme.zip
   ```
2. ติดตั้งธีม — เลือกวิธีใดวิธีหนึ่ง:
   - **อัปโหลดผ่านหน้าแอดมิน:** `รูปลักษณ์ (Appearance) > ธีม > เพิ่มธีมใหม่ > อัปโหลดธีม` แล้วเลือก `dth-theme.zip`
     > ⚠️ ไฟล์ ~46MB อาจเกินลิมิตอัปโหลดของ hosting (มักจำกัด 2–64MB) ถ้าอัปไม่ได้ ให้ใช้วิธี FTP ด้านล่าง
   - **ผ่าน FTP / File Manager (แนะนำสำหรับไฟล์ใหญ่):** แตก zip แล้วก็อปโฟลเดอร์ `dth/` ทั้งหมดไปไว้ที่ `wp-content/themes/` บนเซิร์ฟเวอร์
3. ไปที่ `รูปลักษณ์ > ธีม` แล้วกด **เปิดใช้งาน (Activate)** ธีม "DTH — Disabilities Thailand"
4. เปิดเว็บได้เลย หน้าทั้งหมดถูกสร้างให้แล้ว
   - ถ้าลิงก์ภายในขึ้น 404: ไปที่ `ตั้งค่า > ลิงก์ถาวร (Permalinks)` แล้วกด **บันทึก** 1 ครั้ง (flush rewrite)

> หมายเหตุ: ผมรันอยู่บนคลาวด์ จึงเข้าถึง `10.10.110.10` (วง LAN ภายใน) ไม่ได้ — ต้องอัปโหลด/ติดตั้งจากเครื่องที่อยู่ในเครือข่ายเดียวกับ hosting ครับ

## ข้อจำกัด / หมายเหตุ
- **ระดับการแปลง:** หน้าตาเดิมครบ 100% + แก้เนื้อหาได้ครบทุกหน้าผ่าน editor และมี custom post type 5 ชุด (จังหวัด/เจ้าหน้าที่/กรรมการ/ข่าวสาร/คลังสื่อ)
- ลิงก์ภายในและ path รูปถูกปรับให้ชี้ผ่าน WordPress ให้อัตโนมัติแล้ว
- รหัสผ่าน/ค่าต่าง ๆ ในไฟล์นี้สำหรับ **ใช้บนเครื่อง (local) เท่านั้น** อย่านำขึ้นเซิร์ฟเวอร์จริงโดยไม่เปลี่ยนรหัส
- ถ้าจะนำขึ้น hosting จริง ให้ก็อปปี้โฟลเดอร์ธีม `dth` (พร้อม `Pic/`, `Doc/`, `dth-v2.css`) ไปไว้ใน `wp-content/themes/` แล้วเปิดใช้ธีม
